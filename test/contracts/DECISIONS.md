# Offline executable decisions

`readiness_v1.files` selects the public source-provider and fresh local Hex-payload
consumer cases. Its SHA-256 manifest freezes executable assertions, fixture data,
transport and package inputs. Both consumers run the same cases. Names below are
generated across applicable OpenAI, Ollama and oMLX APIs, Broker and ChatSession;
`<...>` denotes the actual parameter in the ExUnit name. Paths are relative to
`test/mojentic/llm/`. These are behavioral assertions, not schema validation.

The transcript format is a convenience rendering of adapter-observed method,
path, prepared headers and body. Generated HTTP framing headers and TCP state
are outside this library contract. Timeout causes are injected at the transport
boundary; no real timer, socket, sleep or elapsed-time assertion is required.
